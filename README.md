# Tolentino

## Neighborhood Cafe Git practice

This repository is being used for a separate Git and GitHub practice exercise. The cafe demo is not an exam scenario or an exam submission.

The page is a small, responsive cafe landing page built in incremental steps so you can review the changes and commit history.

## Run the page

Open `index.html` in a browser, or open this folder in VS Code and use a local preview extension.

## Practice the Git workflow

```powershell
git status
git switch -c feature/your-change
git add index.html
git commit -m "Describe the change"
git push -u origin feature/your-change
```

On GitHub, open a pull request from your feature branch into `main`, review the diff, and merge it when ready.

Use meaningful commits that describe actual changes. Never create empty commits to reach a target count.
